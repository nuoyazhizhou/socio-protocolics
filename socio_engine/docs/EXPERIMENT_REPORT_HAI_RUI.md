## 一、 实验背景与核心科学假说

在长周期制度史中，海瑞式的“铁腕清官变法”往往面临巨大的基层阻力与系统反弹。本实验旨在利用多智能体沙盘（Multi-Agent Simulation），通过给主官、僚吏、差役、乡绅与小农赋予独立的效用函数、私有信息集与策略偏离空间（SP-POSTULATE-2），检验以下核心机制：

1. **矛盾政令假说（Mandate Conflict）**：当上级政令目标自相矛盾（既要足额解缴税银，又要严禁加派）且缺乏审计闭环时，中介层（书吏/差役）会利用解释权进行“选择性执行”并将成本转嫁至底层，引爆流民逃亡与民变；
2. **铁腕反腐与免疫反弹假说（Purge & Friction）**：当主官强力禁绝火耗并清洗贪腐书吏时，能否通过高压威慑阻断设租？在缺乏替代性专业簿记人员与办公补偿机制（SP-RFC-007）时，官僚系统是否会发生隐性怠工，导致“系统制度熵”激增？

3. **系统免疫反弹的熵增代价**：海瑞的铁腕并没有消灭系统阻力，而是将阻力转化为内部摩擦——系统制度熵从 1.61 飙升至 2.93。官吏群体因寻租链条被斩断而全面进入“消极怠工”与“自保防御”状态。

## 六、 本地复盘与数据查询指南

本项目所有实验数据皆为真实执行输出并完整持久化，任何研究者可直接使用以下命令进行复盘：

### 1. 查询全版本 17 场实验总表与多轮次方差：
```powershell

```

### 2. 提取海瑞重点实验的每季博弈日志与宏观曲线：
```powershell
python socio_engine/scripts/inspect_hai_rui.py
```

### 3. 查看海瑞与各 Agent 的对话心智明细：
```powershell
python socio_engine/scripts/read_hai_dialogue.py
```

### 4. 数据库直接查询 (SQLite3 CLI / Python)：
```sql
SELECT run_id, tick_index, actor_id, action_type, action_payload 
FROM protocol_events 
WHERE run_id = 'run_e422c3a8' 
ORDER BY tick_index;
```
