## 零、共同原则与阶段状态

各组起稿、续写、改题和翻译前，必须回读本组新增的“真实案例与命题检验卡”，按[案例驱动写作与命题检验](../../docs/案例驱动写作与命题检验.md)执行。I组卡统一在[本组计划](I_信道容量与语义边界.md)，案例方法页只保留指针。先确定具体子主张、真实主案及证据链、真实反向材料或有据竞争解释，再形成正文；目标是让证据裁决理论，不预定正面结果。

当前已有文字及本地五篇讨论稿按“概念样章／待真实案例重构”管理，不因写齐、读起来顺或有几处真实引用就计作T3通过。下一轮优先展开真实主案例、补相反材料并交命题回执，不继续批量扩写虚构说明。各组有现成材料，不表示本轮已完成真实叙事与比较；既有案例以后按同一标准复核。

## 二、统一执行步骤

1. **材料起点。**给每案固定时期、目标、实施者、实际受众和分母，逐条记录来源与版本；把已知结局及作者已看过的材料公开登记。
2. **首轮编码。**用事实、行动者解释、作者映射、假说、未知五类记录；保留相反材料、来源链及编码分歧。一个案例跨组使用时，分别说明问题，但不得算作独立重复证据。
3. **机制比较。**先写机制预期出现的具体过程，再和普通协调成本、激励、路径依赖、资源和外部冲击比较；哪些观察支持哪一项必须能区分。
4. **研究规格。**只有取得可信分母、时间线及比较条件后，另定估计方案。跨国四格不等于匹配实验；不能拿四案回归推断理论效应。
5. **中文文章。**有了足够来源再写正文，附公设背景、主要命题组/RFC、规范目标、定性延伸、反例及开放问题。缺证据的原因不写成主因。
6. **双语同步。**中文与来源说明先形成固定版本，再作英文对应稿；保留同一组案例与论断边界。具体按[双语约定](../../docs/双语与写作约定.md)。

## 三、任务顺序与交付物

工作队列建议为II → VI → III → IV → V，I组既有材料继续补证。原因是II有旧样稿与虚构材料可复用，VI有可界定的系统切换和项目评估；III—V需要更多领域、因果与材料核查。此顺序表示编辑优先级，不表示前两组已获证或其他组必须等待所有文章完成。

| 阶段 | 每组要交什么 | 什么情况下停止进入下一阶段 |
|---|---|---|
| T1 材料表 | 至少完成一条可复核事实链，并列缺失、相反材料和来源身份 | 只有标题、摘要或转引，尚不能确认所称事件 |
| T2 比较稿 | 子主张、对象/窗口/分母、真实过程、真实反向材料或有据竞争解释、拒绝/收窄条件 | 只有假想反例，关键变量按结局倒推，或主要来源互相转引 |
| T3 中文案例稿 | 展开的真实主案、反向材料、工程映射、来源说明、命题回执及研究入口 | 以概念、模拟或真实材料点名为主，缺子主张裁决，仍靠未核事实或万能解释承重；标概念样章并补材料 |
| T4 英文对应 | 对应中文版本、术语及逐主张核对记录 | 中英文条件或证据状态不同，材料可用性未说明 |

T1可以先由一人约一至两周完成材料试作，实际取决于档案和数据可得性；不是承诺这段时间内完成历史因果研究。接手者可以只交材料更正，不必认同整套框架或承诺论文。
