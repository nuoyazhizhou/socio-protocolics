两篇arXiv论文能定位，不应继续笼统标为“整篇不存在/全未核”。同样，定位到摘要也不等于确认全部数值和外推。原卡中的Kim相关收益数字、Vals AI/Anthropic成本与Fable规模说法未作为本卡预测依据；后两项尚未逐项定位原始材料，不定性为虚构。

原卡关于Kittur、Ortega研究“一个测参与率、一个测集中度，因此两个都对”的说法，本轮未回到相同时间、语言、编辑者定义和贡献口径逐项核对，故撤回确定性调和结论。即使Agent实验支持H2，也不能单独解决维基百科研究之间的分歧。

## 原卡到v0.2的实质差异

| 原处理 | v0.2处理 |
|---|---|
| “已登记，未开跑” | 待评议草案；无外部登记凭证，不倒填登记人 |
| 标题宣称接入成本与规模正交 | 改成一个问题；H1b仅预测指定条件下的实质等效，不等于独立性 |
| 原P1兼有参与增长与N*不变 | 拆为H1a、H1b，避免与白皮书P1混淆，分别裁决 |
| N*未定义 | 定义固定协作预算与任务下的网格内最优配置上限，区分活跃人数及边界截断 |
| p>0.05视为没有变化 | 预设等效范围；证据不足与等效支持分开 |
| 只列α与N*正相关为反证 | 不再用α替代成本；N*有意义的正负方向变化都可反对H1b |
| 测不了阈值就改用多样性 | 两者都不能直接替代接入成本；不可识别时不启动对应假设检验 |
| 自动运行也可谈参与率 | 要求可识别的加入/拒绝与真实接入，否则另研究启动或时延 |
| 产出非零才算参与 | 参与与合格贡献分开，避免按结果定义分母 |
| Gini与top-1%择一 | 活跃成员标准化Gini为主；全席位指标另报，小团队不直接用top-1% |
| 事后选择最佳点和超峰区间 | 要求在冻结前处理选峰误差、区间选择与层级依赖 |
| R²阈值和跨零统一判未定 | 按各假设的效应阈值、等效范围及可识别性裁决 |
| 推翻P1即框架更强 | 推翻对应局部预测；另一个解释须另行检验 |
| 待核数字当作N*必然存在的先验 | 放回来源线索，既不指定统计先验，也不预设内部峰值 |
| 任何开跑后修改让整卡失效 | 保留冻结原版并公开偏离，具体判断哪些分析变为探索性 |
| Git时间戳不可篡改 | 版本记录与独立登记时间分开 |
| 三个月后必填成立或推翻 | 回顾可记录尚未执行、不可识别或未定；不制造结果 |

## 与白皮书的关系

本次没有修改[白皮书正文](../社会系统协议学白皮书.md)或[速查卡](../核心概念速查手册_CheatSheet.md)。有限资源、自主主体、预期与反馈是问题来源，不能由这些公设直接推出本卡的H1a/H1b/H2。新结果应先与既有架构、组织与协作解释比较；是否需要修改白皮书，依据具体证据另作裁决。

最先需要协作的不是跑出显著结果，而是补齐[卡中的待锁定项](PR-001_Agent协作规模.md#七正式开跑前必须填完的项目)，尤其接入成本是否可操作、贡献是否可归属，以及怎样比较不确定的最优规模。
