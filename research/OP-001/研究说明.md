# OP-001：中介净贡献分析的工程化编排是否帮助读者

版本：设计草案 v0.2｜日期：2026-10-23｜状态：未预注册、未招募、未实验、未取得效果数据。中文原稿，英文待译。

## 1. 研究问题及贡献身份

在同样的流程材料、信息字段和阅读条件下，采用中间件、权限、旁路、版本等工程词汇组织的分析清单，能否帮助具有工程背景的成年读者，更准确地比较中介的保留、删除与替代方案？

这是一项关于**表达与分析方法可用性**的候选研究。它不以“中介可能有净收益”为新发现，不证明社会与计算机同构，也不检验六组核心命题的普遍性。即使结果为正，也仅支持本次工程化编排相对指定对照的局部增益。

它用P1/P2作背景，承接权威总源的O4、RFC-004的适用边界、RFC-005的待检验风险及RFC-007的规范目标，以及RFC-017的迁移核算边界，不改动三条公设—六组核心命题—19项有效RFC（其中007为规范守则）的原有归属。[总源](../../社会系统协议学白皮书.md)

来源与本轮实际阅读范围见[来源表](来源与边界.md)。尚未完成对清单设计、组织流程诊断和工程框架教学实验的系统综述，**不能据此声称题目无人做过或已具发表原创性**。正式研究前，接手者先补这一最近邻检索；若已有等价设计，优先复现、比较或收窄贡献。

本次对照A是一份自编成本与流程清单，B是一份信息相同的工程化清单。A不是经验证的标准量表，也不代表整个制度经济学；B胜过A不能被写成“击败既有社会科学”。

## 3. 目标、边界与可观察量

### 3.1 流程层面的比较

每案先确定同一需求总体、观察期、规则版本和验收要求。候选方案记作：

- **D**：不设置所研究的中介功能，由两端直接处理；
- **M**：保留现有中介安排；
- **M′**：替代安排，须明确保留哪些功能、转移哪些工作及新增成本。

一个“无中介”的M′可能保留了自动校验、后台人员或投诉渠道，不能因改了名称就记作D。每案须说明谁有权作出调整，以及原有安全、服务可及性、复核条件是否保持。

记录以下量，**不合成社会健康总分**：

| 量 | 单位与含义 | 主要限制 |
|---|---|---|
| 总人力投入 | 固定总体与期间内，各相关主体处理、返工、支持及迁移的人分钟 | 同一时间不得重复计入两类；只记机构内部会漏掉申请者负担 |
| 等待与完成时延 | 每件需求的日历分钟/小时 | 不能与人分钟直接相加 |
| 服务质量 | 按事前任务标准合格、按期完成的件数与分母 | 初次差错、最终完成与按期完成分别记 |
| 覆盖 | 尝试申请、登记、完成及放弃的件数 | 未登记不等于没有需求，也不直接等于有效需求 |
| 费用与分配 | 支付款、收款方、价格单位及外部负担 | 支付转移不自动等于同额社会资源损失 |
| 权限与纠错 | 谁能解释、拒绝、改规则，谁可退出、复核 | 先描述可核事实，不能仅凭中心化或高价认定寻租 |

不同量无法统一折算时，报告代价与结果的向量及约束；不通过任意权重把权利、时延和费用压成一个看似客观的“净价值”。

净贡献不是由M存在与否定义的。应比较可行方案的独立成本与结果。某功能在短期未触发，不足以认定其没有恢复或尾部风险收益；反之，也不能用无法核查的“可能有灾难”无限豁免任何关口。

### 3.2 读者层面的比较

主指标为参与者在未见案例中的**判读得分**，每案0–10分，取个人均分后除以10归一化到[0,1]。评分细则需在分组前冻结；五个维度分别涉及边界、计算、质量与覆盖、方案选择、未知信息。细则见材料包。

次指标包括完成时长、工程术语误解、无依据断言“多一层必坏”的次数，以及误把费用转移当资源耗费、把登记分母当全部需求的次数。自评“很有启发”只作主观体验，不替代正确性。

## 4. 最小执行单元：先做材料预试

本包已提供三张公开虚构案例卡、A/B两份清单、统一答题格式和条件性参考答案。公开题只用于检查材料是否看得懂、答案是否存在歧义，**不用于证明B的优越性**。

接手者的第一份交付可以仅包含：

1. 逐案确认数字、单位、方案与约束是否足够，指出至少一个可能改变答案的缺失条件；没有则说明未发现，不必制造问题。
2. 检查两份清单是否在信息、长度和培训时间上公平；同时修订两方，保留版本差异。
3. 请少量目标读者试读，例如总计8–12名自愿成年人。该规模只是发现文字问题的可行预试，**不是效应检验所需样本量**，没有参与者时也可先完成前两项。
4. 交付去标识化答题、误解清单和修订记录。研究者若要实际招募和使用答题作研究，应先确认适用的知情同意、隐私和机构要求；本轮未进行招募。

不能让读者先看大众样章及答案，再把其答题正确率作为框架有效的证据。可以另做读后理解测试，但须另名、另列研究问题。

## 5. 后续受控比较的候选设计

预试后，使用**全新、未公开且未用于训练的案例**进行两组比较。案例应包含生产性中介、多余环节、混合功能及证据不足等情况；不按政治立场配额，也不只写B最擅长的题型。

- 目标总体暂限定为有流程、测试、运维或开发经验的成年读者。不能据此推断全体大众或社科学者。
- 采用参与者间随机分组；按事先登记的工程背景分层。每人只使用A或B，避免同人切换造成迁移学习。
- 两组获得相同题干、信息和答题格式，给予相同培训、答题时间及可用工具。清单字符数差异控制在10%以内；字符接近不是认知负荷相等，预试仍需检查。
- A/B都包含全部关键问题；不把A故意简化成“只数层数”，也不向任一组额外提供答案、案例解释或作者声望提示。
- 正式案例与条件性参考答案由题目编写者之外的领域/方法评阅者先复核。对本质有争议的判断，列允许答案与理由，不硬造唯一金标准。
- 评分者尽可能不知道分组；原始答题若暴露术语，应报告盲法可能失效。至少两人独立评分并保留初始结果与分歧裁决，不能仅报裁决后的完全一致。

**尚未具备**：新的正式题库、外部材料复核、正式样本量及预注册记录。因此本文件是可接续的设计草案，不是“现在即可开展有效实证”的完整资格证明。

## 6. 预设增益与可能失败

令Δ为B组与A组的平均归一化判读得分之差。候选的最小有意义增益取**δ=0.10**，即10分制平均增加1分。这是本设计暂定的实用阈值，不是社会常数或由理论推导出的数值；预试后若调整，须先发布新版本，再用新的确认性数据检验。

正式执行前，锁定样本量、分层方式、缺失和剔除规则、题库版本及95%置信区间算法。样本量须按δ、得分变异和检验要求规划，不能把8–12人的预试直接升级为验证。分析以参与者为随机化单位，不把同一人的多道题当作独立样本；题目样本的有限性另行报告。

| 预先定义的区间结果 | 可以说什么 |
|---|---|
| Δ的95%区间下界达到0.10，且不存在未解释的严重材料/评分偏差 | 支持在该人群、任务与A/B版本下达到预设的得分增益；时长和错误类型仍须完整报告 |
| Δ的95%区间上界低于0.10 | 本次比较不支持预设的最小有意义增益，不能继续声称已达该目标 |
| 区间包含0.10且下界小于0.10 | 证据尚不能裁决预设增益；不以统计不显著冒充无效果 |

若B增加无依据的“寄生/死锁”判断、耗时明显增加，或只在有意迎合框架的题目中占优，即使平均分上升，也必须报告这些代价，不概括为总体更好。

若只报告同一批固定题目的结果，结论仅适用于这些题目；要声称可推广到其他案例，需增加题目来源、抽样和复现。若更换术语而表现无变化，也可能意味着普通语言已经足够，不应再通过补设“好中介/坏中介”保护框架。

## 7. 数据与交付格式

最小数据记录如下，不采集真实姓名、单位、政治态度或现实案件材料：

| 字段 | 类型 | 含义 |
|---|---|---|
| participant_id | 字符串 | 随机化匿名标识 |
| phase | 枚举 | pilot / confirmatory；不得混用 |
| arm、background_stratum | 枚举 | 分组、分组前记录的背景层 |
| case_id、case_version、checklist_version | 字符串 | 题目与干预材料绑定 |
| answer、missing_information | 文本 | 原答、所需补证，不由研究者补写 |
| duration_seconds | 非负数或缺失 | 同一计时规则下的完成时长；中断另记 |
| rater_id、rubric_version、scores_initial | 标识及整数向量 | 各评分者初始五项0–2分 |
| adjudicated_scores、adjudication_reason | 向量及文本 | 保留裁决依据，不覆盖初始评分 |
| exclusion_reason | 枚举或空 | 按预先规则决定，不能因答错而剔除 |

接手者交回版本化材料、匿名数据、评分分歧、实际分析和未支持的结果。没有取得同意开放的答题不公开；可以先共享字段说明和汇总结果。LLM生成的答题须另标，不得伪装成人类样本。

## 8. 本包能提供什么、还需要谁

已提供：大众样章、问题定义、三个算例、A/B清单、答题格式、评分起点、来源及原稿映射。

仍需贡献：流程/组织领域的材料审查、清单与人因研究的最近邻检索、未见案例建设、研究设计与样本量复核，以及真实读者试读。是否发表、署名、使用许可与贡献认可，应按实际合作另行约定；本包不代任何人作承诺。

最小可接手成果可以是一次有依据的材料修正，也可以是发现本问题已有等价研究。复现得到零增益或负增益，同样应保留。只有比较真正完成后，才讨论扩展到真实组织现场或其他人群。

## 9. v0.2补充的执行边界

本次仅整理材料及核对外部研究相关段落，没有招募、随机分组、评分或效果估计。浙江制度文件与外国既有实证另见[现实案例表](../cases/II-CN-A_住房公积金登记工作去向.md)及[外国研究核对](../cases/II-INT_审计与驾照研究核对.md)；它们不进入三道虚构题的数值，也不是本实验的人类答题数据。

正式研究还须预先处理缺答、退出、超时、未遵从清单、重复参与和材料泄露；按分配组报告主要分析，不能仅保留完成者或理解工程术语者。评分缺失不自动赋零，具体缺失处理须先定，并报告敏感性。外部评分者须检查评分是否偏爱作者的概念；发现等价的普通表达应同分。

本包区分两个问题：一是中介怎样影响真实流程，二是工程化表达是否改善读者判断。OP-001直接检验第二个问题；即使得分提高，也不能据此宣称RFC-005的复杂性—寻租反馈已成立。公开题中的对照是成本与流程清单，不是整个制度经济学。

版本、来源、许可和实际贡献分别记录。尚未授予统一再分发许可；可先按仓库参与说明提交修订建议，不以GitHub托管推定获得任意改编授权。
