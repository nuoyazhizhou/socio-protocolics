# 案例选择与比较方法：怎样让成功和失败都能修正框架

版本：探索方案 v0.4｜日期：2026-10-23｜语言：中文原稿，英文待译。

状态：已知部分历史结局后制定的探索方案，不是历史事件发生前的预测，不是正式预登记，也没有完成跨案例编码或因果效应估计。本文规定接下来如何整理证据，不能据此宣称四案例已验证白皮书。

## 零、共同规则与I组主题入口

[案例驱动写作与命题检验](../docs/案例驱动写作与命题检验.md)适用于六组。I组的目标子主张、真实主案、反向材料、改判条件、普通解释及理论回写，统一维护在[信道容量与语义边界主题计划](主题计划/I_信道容量与语义边界.md)的检验卡；本页不再平行复制，避免续写时出现两个版本。

以下保留语言改革案例的选择方法、既有候选与来源阅读范围。材料登记不等于效果验证；文章先展开真实过程，每篇交命题回执，概念样章不算T3通过。

## 一、研究对象与选择原则

首轮范围是“面向较广受众的书面表达或文字规范变更，如何从倡议进入使用”。观察者、改革者和使用者的目标可能不同，先记录原行动者的目标，再单列本项目的评价目标。

中国和外国各纳入制度采用与受阻/撤回候选，使读者能比较不同路径；这是有意选择差异的探索样本，不是随机抽样，不用于估计改革成功率。不能因案例不符合框架就删除，也不能把政治立场、人物评价或结果好坏当作机制编码。

先登记全部实际考虑过的候选、对象、时期、来源条件、纳入/暂缓理由和已知结果。优先材料可追溯、结果可分层、能找到相反证据的案例。若没有合格失败材料，如实保留缺口，不编造失败。

胡适与二简字并非同一种改革；美国2010文书规则与1906拼写倡议也不等价。四格是传播和探索的组织方式，不能当作已经控制了背景的实验设计。再增加同领域近邻及同案内部差异，才可能进一步辨别机制。

## 二、先定义成败，不给整案一个总标签

每案固定起止点、对象、地区、文书/教材类型、受众、实施者及分母；逐维记录，禁止以一项替代另一项：

| 结果维度 | 可以观察什么 | 不能替代什么 |
|---|---|---|
| 正式进入 | 公布、授权、适用范围、生效与撤回文件 | 不能代替真实采用或效果 |
| 实际采用 | 同类教材、文书、刊物或机构中采用份数及总体 | 出版不等于使用；样本不等于全国 |
| 理解与任务效果 | 错误、正确率、完成时间、训练要求 | 文本更短、笔画更少不等于更易理解 |
| 持续及兼容 | 相同时点的保留、混用、返工、回退及替换成本 | 撤回不等于每个词形或全部目标均失败 |
| 分配与可及性 | 新旧读者、教师、出版者、机构等谁受益、谁负担 | 机构节省不等于总体成本下降 |

同一案可以制度采用成功、理解收益未定、迁移成本偏高。窗口优先同时列改革后1年及5年的可得记录；未到窗口或缺记录标为缺失，不能补零。另保留关键事件时间线。不同窗口不可直接当作二元成败对照；若材料条件迫使改窗口，记录改动和理由。

## 四、怎样研究失败原因

先提机制及其可观察后果，再查材料。下表的关系是待检验解释，不是已经查明的原因。

| 候选机制 | 应寻找的过程证据 | 会削弱该解释的观察 |
|---|---|---|
| 学习与理解成本 | 同类任务下的训练、误读、返工和纠错记录；区分初学者与熟练者 | 理解效果相近，而变化主要紧随授权或预算变动；所谓降低成本只有笔画/字数依据 |
| 兼容与转换成本 | 教材、工具书、字库、印刷和新旧使用者之间的转换工作，明确谁支付及何时发生 | 已具低成本兼容、实际转换负担很小，仍发生同样受阻；同期非转换因素解释更强 |
| 配套与激励 | 培训、材料供给、采用机会和拒绝行为；正式认可前后的实际行为 | 有配套却不采用；没有正式认可已持续采用；利益变化能解释全部差异 |
| 授权与协调 | 谁能决定、谁能阻止、执行范围和冲突文件；区分实际权力与工程权限类比 | 没有预设的冲突，或同样协调结构下结局不同；变化由其他冲击先行引发 |
| 反馈与调整 | 试用、投诉、修订、暂停、回退的时间及内容 | 未依赖所称反馈已发生同样调整；只凭结局才给过程贴“PDCA”标签 |
| 外部条件 | 政治联盟、教育扩张、经济和媒介变化的独立时间线 | 所谓协议因素只重复描述这些变化，没有独立证据或可区分含义 |

对CN-S2，所附请示提出过规范稳定、既有工具书和字库等理由；当前只能登记为决策者列举的理由。要论证它们实际促成暂停/废止，须补之前已经出现的采用与转换困难记录，检查修订、政治与组织解释，并寻找与主张相反的部门或使用者材料。

不得把所有失败统一写成“技术债”“阻抗”或“没有赛马”。授权争议也不能未经成本和行为材料就改称“兼容成本”。一种解释若能包住所有相反结果，却无法指出什么会使它失败，就还不是合格的案例假说。

## 五、比较和因果识别的实际步骤

1. **先建时间线。**每一条记录区分事件、当事人解释和后来研究；先后顺序必要但不充分。只有撤回文件，不能倒推此前所有使用者反对。
2. **按统一问题编码。**两个中国案例和两个外国案例使用同一字段；同一材料转引多次只算同一来源链。只依一方解释的环节单列缺口。
3. **做案内比较。**在条件可比且有材料时，看不同年级、部门、文书类型、字形或试点的差异。必须同时记录选择进入的原因，不能将试点与非试点天然当作随机组。
4. **做近邻比较。**二简优先补1956方案等同领域资料，避免仅跨时代跨国对照。近邻比较仍不能自动消除教育水平、政治和媒介条件差异。
5. **区分预测。**让协议解释、转换成本/路径依赖、语言政策、组织激励等既有解释回答同一问题，写出在哪种观察下会作出不同判断。含义相同就登记为重述，不硬造新机制。
6. **有合格数据再估计。**如取得足够前后记录及可信比较，另写识别方案；四个历史故事不能直接做可靠回归、因果效应或成功率推断。没有条件时只报告过程证据、竞争解释和不确定性。

本轮已知案例结局，任何分析冻结只约束后续工作，不能包装成此前的盲预测。今后留出新材料或新案例时记录哪些结局/材料此前已知；只做作者分析留出时不冒充独立盲测。

## 六、怎样判断白皮书是否增加价值

每案最后提交三列：框架促使检查的具体问题、普通解释是否已覆盖、带来的新增证据或错误纠正。分别评估：

- 表达价值：读者是否更容易理解；需要公平对照，不能以作者感觉或点赞计分。
- 方法价值：在相同材料下是否少漏分母、转换负担、权限或反例；工程表示也可能增加误判。中介样稿OP-001属于这类候选，不与[PR-001](PR-001_Agent协作规模.md)混号。
- 机制价值：相对既有解释是否产生可区分且得到支持的观察；需要独立操作化和相应识别，不由术语或案例数累积自动获得。

如果工程说法没有增加判断或预测，就收窄为教学重述；如果与证据冲突，就修改或放弃具体应用。保留无法解释、零增益和负增益的记录。不能把正反结果都改写成对同一命题的支持。

## 七、接手者的第一份交付

已有[CN-S2文件与证据表v0.2](cases/CN-S2_证据起点.md)，明确登记为001过强简省外推的反向检验候选，而非已测认知反例；目标是把事实和原因分开，不必先写整篇文章。该表只有一条官方转发来源链，尚缺独立材料。继续补证使用字段如下：

`case_id、范围与窗口、source_id、原作者/机关、成文日期、事件日期、文献类型、原句与定位、转录/影像状态、结果维度、机制假说、支持或反对、竞争解释、来源链、未知项、编码者与分歧、版本`

可先从已定位转发文本抽取提出、停止试用、修订、废止四类记录，再补各项所引原通知与同期反馈；查不到也记录检索范围。数字缺失标NA，行政理由与实际成本各设字段。材料准确、论断不过界即构成有用交付，不以支持白皮书为验收条件。

后续每案形成中文文章、来源与边界说明、比较表及一项具体开放任务，再按[双语约定](../docs/双语与写作约定.md)翻译。涉及命题变化时增量修订总源，不能仅修改审查报告。
