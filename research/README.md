# 可以接手的研究问题

前三张卡承接[胡适文章](../articles/hu-shih/如何评价胡适的作品.md)；OP-001承接[中介文章](../articles/intermediary/删掉两道审批_工作真的少了吗.md)；OP-002开放研究认证、授权与组织自主性；PR-001另行研究Agent协作规模。它们是材料核查和研究设计草案，均未正式预登记、未按各自方案开展实验，没有效果数据。

## 提出问题，也接受问题被否定

白皮书可以提供可接手的问题、候选机制与检查接口，不要求作者亲自完成每项经验研究。参与者可自由选择材料和合适的方法，也可指出研究问题已被既有理论覆盖；不必先支持协议论，不必同时完成建模、仿真和比较历史。

每项课题写清具体子主张、已有解释、支持与改判观察，以及对应白皮书的位置。不同思路可以先提出，方法创新与解释增益由后续比较判断。维护者负责定义和来源质量，不以等待外部论文替代当前应做的核查。

研究成果按“子主张—证据—竞争解释—裁决—拟回写位置”回收。支持只加强相应条件下的子主张；反对、零增益和更好解释应促使撤回、收窄或重写相应预测，不能把两种结果都登记为获证。证据不足就暂缓裁决，不据一项论文宣布整本白皮书成立或失效。具体执行沿用[案例驱动写作与命题检验](../docs/案例驱动写作与命题检验.md)，提交与授权见[参与说明](../CONTRIBUTING.md)。

## 课题入口

跨案例工作先按[案例选择与比较方法](案例选择与比较方法.md)登记范围、结果维度、竞争解释和证据。该文件是探索方案，不是已经完成的跨国比较或新的正式预登记卡。

[I—VI组主题实施计划](主题计划/README.md)已列语言接口、中介、承诺、权限、反馈、迁移六组的具体中外候选、来源起点、拒绝条件与首项任务。[I组独立计划](主题计划/I_信道容量与语义边界.md)统合H01—H03、既有案例材料与002命名/回应任务；002尚未写入胡适正文，已交[命名与回应初表](cases/CN-HU_命名与回应对照.md)；[二简证据表v0.2](cases/CN-S2_证据起点.md)记录反向检验身份及新增线索处置，不宣称认知效应已证。它们不替换H01—H03或PR-001，也不表示案例研究已经完成。先交材料，再决定能支持什么结论。

OP-001已提供[研究说明](OP-001/研究说明.md)、[材料包](OP-001/材料包.md)及[来源边界](OP-001/来源与边界.md)。公开题与答案只能作演示和材料预试，不能据其训练后的高分验证方法。真实流程另看[浙江登记工作去向](cases/II-CN-A_住房公积金登记工作去向.md)与[外国研究核对](cases/II-INT_审计与驾照研究核对.md)；没有把制度文件变成实测数据。

OP-002已提供[研究说明](OP-002/研究说明.md)和[来源与边界](OP-002/来源与边界.md)，将认证投入、控制权、保护性授权、探索空间分开登记为候选假说。现有初核材料只校准分类，不构成中西因果对照；它连接IV/VI组的具体问题，不新增RFC或宣称核心理论获证。

最小任务以一人约一至两周的材料试作为目标，实际时间依资料可得性调整。试作的成功是资料准确、方法可复核；不能把试作按时完成当作理论成立。

预登记需要在相应数据收集或分析开始前锁定计划，并明确已有知识、假设、变量、排除规则、样本规划和分析方式。探索性发现与后续检验分别标记。Git 记录可追踪版本，但提交日期可指定、历史可改写；需要登记时，使用有独立时间记录的登记服务，并公开后续偏离。[Git 日期说明](https://git-scm.com/docs/git-commit)、[OSF 登记说明](https://help.osf.io/article/330-welcome-to-registrations)。
