# 可以接手的研究问题

前三张卡承接[胡适文章](../articles/hu-shih/如何评价胡适的作品.md)；PR-001另行研究Agent协作规模。它们是材料核查和研究设计草案，均未正式预登记、未按各自方案开展实验，没有效果数据。

| 编号 | 问题 | 第一份可提交的成果 |
|---|---|---|
| [H01](H01_表达与理解成本.md) | 表达显式化是否降低理解成本？ | 一组经领域读者核对、信息尽量等量的对照文本 |
| [H02](H02_正式地位与采用.md) | 正式地位通过什么途径影响采用？ | 少量同期文本的出处、编码和反证记录 |
| [H03](H03_规则与实际迁移.md) | 颁布规则与实际迁移相隔什么？ | 一份训令与两份教材的范围核对表 |
| [PR-001](PR-001_Agent协作规模.md) | 降低接入成本，是否改变最优Agent协作规模？ | 可记录加入/拒绝及成本的流程说明，或一份贡献记分方案 |

PR-001当前仍有待锁定参数，公开目的是征求方法反馈，不能直接当作已登记的实验方案执行。[来源与修订说明](PR-001_来源与修订说明.md)说明它与原卡的区别。

最小任务以一人约一至两周的材料试作为目标，实际时间依资料可得性调整。试作的成功是资料准确、方法可复核；不能把试作按时完成当作理论成立。

预登记需要在相应数据收集或分析开始前锁定计划，并明确已有知识、假设、变量、排除规则、样本规划和分析方式。探索性发现与后续检验分别标记。Git 记录可追踪版本，但提交日期可指定、历史可改写；需要登记时，使用有独立时间记录的登记服务，并公开后续偏离。[Git 日期说明](https://git-scm.com/docs/git-commit)、[OSF 登记说明](https://help.osf.io/article/330-welcome-to-registrations)。
