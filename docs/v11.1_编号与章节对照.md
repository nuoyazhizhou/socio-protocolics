# v11.1编号与章节对照

2026-10-26｜历史记录：本页保留v11.0→v11.1的编号和章节。当前使用[v11.2对照](v11.2_编号与章节对照.md)；下列链接已限定为v11.1入口，表中节号仍为当时位置。v11.1只做结构整理、编号同步和主张身份澄清，不表示新增实证结果。

## 编号规则

v11.1当时的SP-RFC-001—021按六组连续排列；每项都有独立正文条款节。v11.0的014已合并到其004，v11.1统一登记为005。旧编号不与新编号混用：例如v11.0的019是文本解释应用，v11.1的019是迁移核算。

v11.1当时的`sp-rfc-XXX`采用本页含义；当前正文的同名锚点已采用v11.2含义。追踪本页条款使用`legacy-v11-1-rfc-XXX`，更早版本使用`legacy-v11-0-rfc-XXX`。不能保证以前未带版本的同号链接仍指向同一内容；引用应列版本和条款名。
