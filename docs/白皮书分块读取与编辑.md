# 白皮书按标签读取与编辑

日期：2026-10-27。正文仍以[白皮书](../社会系统协议学白皮书.md)为唯一公开定义源；标签只划分读写边界，不新增理论层级或RFC。

## 固定边界

公开正文有9组HTML注释标签。标记不显示在Markdown成文中，原有章节、RFC及legacy跳转锚点全部保留。

```markdown
<!-- SP:BEGIN chapter-07 -->
<a id="chapter-7"></a>

## 第七章：第六组：迁移核算与试验筛选

……章节内容……
<!-- SP:END chapter-07 -->
```

| chapter-01 | 研究定位、原语、公设与六组边界 |
| chapter-02 | 信道容量与语义边界 |
| chapter-03 | 中介净贡献、复杂性与规范选择 |

开始标签位于章节原有锚点之前，结束标签位于下一章开始之前。第八章在结语前结束；题记、目录和结语不属于章块。附录直到文末。章节内的分隔线和空行也属于原文，不另作重排。

ID是机器定位标识，标题措辞改变时不改ID；本版要求8章加附录各出现一次、按当前顺序排列、无嵌套或交叉。将来若重排结构，须同步调整检查规则，不能只挪标签。暂不为每项RFC另加边界。

## 先列目录，再读目标

[工具](../tools/whitepaper_blocks.py)只依赖Python标准库，要求Python 3.10+。以下命令在仓库根目录执行；工具的相对输入输出路径均以仓库根为准。

```powershell
python tools/whitepaper_blocks.py list
python tools/whitepaper_blocks.py read chapter-07
python tools/whitepaper_blocks.py read appendix
```

`list`只输出9个ID、标题、大小和区块原始字节的SHA-256；可加`--json`获得结构化结果。`read`的标准输出仅含标签之间的完整原文，标签本身不输出，哈希写到标准错误。

程序仍会在本地读取文件，但只向终端或模型返回指定正文，降低的是上下文与定位负担。小改动可先搜索本章的具体段落，不必每次整章重写。标签不会自动补齐依赖：修改条件或定义时，另读有关O/P、跨章接口和附录生成卡。检查018可先读第七章，再补017接口及附录对应证据卡；不能因只读一章就跳过必要背景。

## 导出、预览与明确写入

先导出区块，保留当时的哈希；`--out`只创建新文件，拒绝覆盖已有编辑稿：

```powershell
$blockInfo = python tools/whitepaper_blocks.py read chapter-07 --out .local/章节编辑/chapter-07.md | ConvertFrom-Json
```

编辑导出的文件。它含章节标题及原有锚点，不含BEGIN/END标签；保存为无BOM的UTF-8，并保留末尾换行。不同编辑会话中需保留读取时的`sha256`，不要改完后重新取哈希来绕过冲突。

先只查看差异：

```powershell
python tools/whitepaper_blocks.py replace chapter-07 --from-file .local/章节编辑/chapter-07.md --expect-sha256 $blockInfo.sha256
```

默认只预览，不写正文、不生成备份。核对后使用同一参数并明确加`--write`：

```powershell
python tools/whitepaper_blocks.py replace chapter-07 --from-file .local/章节编辑/chapter-07.md --expect-sha256 $blockInfo.sha256 --write
```

工具核对目标原文哈希、完整标签结构和现有锚点，拒绝删去或重复原有锚点。写入时先保存完整原件到`.local/章节编辑备份/`，通过同目录临时文件替换正文，保留区块外全部字节。其他章节在读取后、计划生成前已有的修改会从最新正文保留；计划生成后再次发现正文变动则拒绝写入。工具自身写入使用锁文件，但不能代替外部编辑器的协同控制或版本管理。

没有差异时不写入、不备份。空内容、缺结束换行、BOM、标签缺失/重复/嵌套/交叉、章节归属错误、丢失锚点、哈希不符或已有工具写锁都会拒绝操作。围栏代码块里的标签示例不计为真实边界。

区块编辑器只检查读写边界和锚点，不代替正文、公式或代码审查。实际修改后仍按[门禁约定](../AGENTS.md#四-自动化质量门禁verification-gate)运行内容回归与公开范围检查。

## 内部版与验证

本地内部版使用相同标签格式，但独立读取、独立修改，不从公开版整章覆盖。通过`--file`明确指定目标；默认始终是公开正文。内部版和备份不进入公开清单。

```powershell
python tools/test_whitepaper_blocks.py
python tools/verify_all.py
python tools/test_verify_structure.py
python tools/check_public.py
```

常规门禁已检查9组边界；分块工具的负向与写入测试见[回归脚本](../tools/test_whitepaper_blocks.py)。维护者修改内部版或共同规范时，仍须按AGENTS显式运行带`--internal`的门禁。通过只说明指定结构与参考实现检查通过，不表示全文实证或数学证明完成。
