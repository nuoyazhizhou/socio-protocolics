# 公开修订说明

版本：v0.5｜日期：2026-10-23｜对应[正文](如何评价胡适的作品.md)。v0.3、v0.4记录保留；v0.5新增目标、实施依赖与二简比较，出处及读取范围见来源说明。完整工作底稿与逐行差异仅在本地保存。

## v0.3实质修订记录

| 原处理 | 此版处理 | 原因 |
|---|---|---|
| “那把尺子本身就是错的” | “只用这一把尺子不够” | 保留贡献维度，不取消文学评价 |
| 价值/贡献分别由批评家/历史裁定 | 改为各自所需的材料 | 三分法是分析选择，不是互斥学科边界 |
| 《尝试集》之前一个现代诗样本都没有 | 承认结集前已有创作与发表 | 避免把结集当成实践起点 |
| 白话“跑了六百年”、四年完成转换 | 按文体与场景讨论；只说数年间有制度推进 | 起点与实施对象不能混用 |
| “文言只在省篇幅上赢” | 加入跨方言书面交流、典籍延续等待比较功能 | 不用自选单项指标宣布全面输赢 |
| 文言/白话均39 bit/秒 | 从对照表移除，并解释研究边界 | 语音研究不测两种文体的阅读理解 |
| 编码复杂度统一倍数、AV1仅2021年后支持 | 改为依实现与硬件讨论；订正2020年官方资料 | 不把特定条件扩大为通则 |
| 人口像固定档位的设备 | 比方仅代表训练条件，人会学习与自主选择 | 符合主体自主边界 |
| 技术竞争、进化“独立验证”白话解释 | 改为帮助提出问题的类比 | 不同领域材料不能直接验证社会因果 |
| 文言输给印刷机、电报、义务教育 | 纳入制度、学校、市场、政治文化与行动者 | 撤回单一技术归因 |
| 字典教科书“不算数” | 恢复原文“重要但不能单靠” | 不把不充分条件说成没有作用 |
| 规范发半年无人动，样本出来才跟进 | 删除该因果叙述 | 与原稿自己的时间线冲突，且缺影响识别 |
| 故意留下缺陷供模仿 | 区分保存既有作品的历史用途与故意制造缺陷 | 四版自序支持前者，不支持后者 |
| 四版本实验得出文法是主因 | 改为三种阅读方式；保留术语疑问并撤回排序 | 信息增量、顺序与背景未控制 |
| 文言不可教、科学白话无损 | 两者均需训练，任务效果另测 | 不把文体标签当成认知效果 |
| 能否互译决定范式/协议革命 | 改成研究迁移、兼容与权威的多个问题 | 一项维度不构成充分分类判据 |
| 只能预测失败，成功逻辑上不可预测 | 撤回；成功失败均接受条件与结果检验 | 防止框架免疫于一部分反证 |
| 以赞颂胡适收尾 | 留下三张开放问题与框架入口 | 把关注转换成可提交的具体贡献 |
| 尾注只简述借用术语 | v0.3补列三个建模起点、局部机制假说及项目公开入口，注明对应版本尚未推送 | 便于知乎读者找到白皮书，并区分公设、假说和案例证据 |
