所有新稿与既有稿续写须遵守[案例驱动写作与命题检验](../docs/案例驱动写作与命题检验.md)：真实主案展开，核对真实反向材料或有据竞争解释，交具体子主张裁决；概念样章不计T3通过。

案例文章展示如何提出和检查问题。它们不是六组核心命题的证明清单。后续案例应包括失败、部分成功和不适用的情况，避免只挑能讲通的故事。

中介概念样章v0.3保留三道明确标识的虚构题，另链接中国制度材料和两篇外国研究的局部核对，不把几案包装为匹配实验。对应[OP-001](../research/OP-001/问题卡.md)研究设计仍未预登记、未招募、未取得效果数据；中文先行，英文待译。

胡适文章提供单版本合集（v0.6）与两篇式深化精修版（[上篇·文学与制度](hu-shih/如何评价胡适的作品_上篇.md) 与 [下篇·科学与工程](hu-shih/如何评价胡适的作品_下篇.md)），包含[目标与当前交付的比较](hu-shih/如何评价胡适的作品.md#reform-scope)，并保留[框架尾注](hu-shih/如何评价胡适的作品.md#article-framework)，区分主要引用、规范目标和定性延伸。全篇以“学术做承重墙，人话做精装修”为交付标准。
