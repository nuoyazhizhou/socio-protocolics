# 社会系统协议学 · Socio-Protocolics

项目地址：[nuoyazhizhou/socio-protocolics](https://github.com/nuoyazhizhou/socio-protocolics)。

用协议、接口、中间件、迁移和反馈等工程概念，整理社会协作中的问题。这里保存白皮书、面向公众的案例文章，以及可以接手检验的开放问题。

这是一个接受修订的研究纲领。工程类比帮助提出问题；历史解释、数学命题和经验效果分别需要自己的证据。

## 案例怎样回到理论

每篇案例区分四件事：外部材料说了什么、本文借用了什么概念、增加了什么假设、哪些观察会迫使我们修正。文章获得关注不等于框架得到验证；反例、零增益和已有更好解释，都应进入修订记录。

胡适案例首先提出理解成本、正式采用和样本扩散问题；这些仍是待比较的局部解释，没有据此宣布公设或六大定律获证。[案例与白皮书的对应关系](articles/hu-shih/来源说明.md#与白皮书的对应关系)列出具体边界。
